# Binance Options REST API — public market data

Public market-data endpoints of the Binance European Options REST API. 12 requests, generated from the official Binance Postman
collection (`binance/binance-api-postman`) and validated against the live API.

- **Market Data** — 12 requests

## Usage

Open this folder as a collection in Bruno (or run `bru run -r . --env production`
with the Bruno CLI). Select an environment first:

- `production`: https://eapi.binance.com

All endpoints are public — no credentials required.

Private (signed) endpoints are intentionally not included.
